# MX1

MX1 is a code editor for Windows 10 and 11 (x64), built from the open-source
[Code - OSS](https://github.com/microsoft/vscode) project (version 1.146.0) under the MIT License.

- Extensions come from [Open VSX](https://open-vsx.org).
- Builds are produced by GitHub Actions (`.github/workflows/mx1-build-win32.yml`, staged at `ci/mx1-build-win32.yml` until it is enabled) and published on the
  [Releases](../../releases) page as a portable zip (`MX1.exe` inside) and a per-user installer.
